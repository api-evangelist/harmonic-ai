## APIs

- **Harmonic REST & GraphQL API** — REST API for company search, enrichment, saved searches, list management, and bulk operations, plus a full GraphQL endpoint for flexible queries across companies, people, investors, lists, and custom fields. Auth via apikey header or OAuth 2.0 bearer tokens. (`https://api.harmonic.ai/`)
- **Harmonic MCP Server** — Hosted, agent-native MCP server exposing 40+ tools for enrichment, search, saved searches, lists, investors, network mapping, batch lookup, custom fields, and team. Listed in the Claude Connector store and ChatGPT Apps directory. Auth via OAuth 2.0 or API key. (`https://mcp.api.harmonic.ai/`)
